# UI Fix Applied

This version improves the Station Tracker layout for desktop and mobile.

## Main fixes

- Search results no longer stretch the whole header.
- Desktop header is now a clean three-column layout: title, search, action buttons.
- Mobile header stacks neatly: title/buttons first, search below.
- Search dropdown is now an overlay with controlled height and scrolling.
- Stats cards are more compact and consistent.
- Sidebar and bottom sheet spacing is improved.
- Map now keeps the remaining screen height instead of being pushed down by search results.
- Buttons, popups, and form controls have cleaner rounded styling.
